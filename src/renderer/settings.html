Surface

Glass blurs what's behind the island. Pure black is true black, for OLED screens. Rosé, Lavender, Peach, Sakura and Candy glass are soft themes.

Glass and Candy glass don't show in screenshots or recordings — Windows keeps them out of captures. While OBS records, the island turns to plain glass.

Island

Island border wallpaper

The image shows only in the island's border ring — the inside stays transparent glass. The file is copied onto this PC, so it keeps working if the original is moved or deleted. Presets are built-in gradients.

Live wallpaper

The video file stays where it is (videos are large — it is not copied). If you move or delete the file, the wallpaper turns itself off and tells you.

Taskbar

System tray

— opens Windows Settings

Windows does not expose other apps' tray icons to a desktop app, so the taskbar shows live system-status icons (volume, Wi-Fi, battery) instead of the apps' own tray icons.

Windows' taskbar

Windows' taskbar hides only while the OpenIsland taskbar above is on — it never hides on its own. (v1.0.0 item D.)

Gaming

FPS comes from Windows' own frame events (nothing injected into the game, one-time permission in the Gaming tab). Borderless / windowed fullscreen only.

AI agents

An AI-agents section shows what your coding agents are doing — Claude Code, Codex, Antigravity, Hermes or your own agents — and nudges you when one needs you (for example, when it is waiting for a permission). OpenIsland does not build this in v3.0.0: watching another app's agent processes and nudging on their state is a separate piece of work, and PJ decides later whether he wants any of it. Nothing here sends data anywhere.

Tools

Screenshot / region snip / screen recording (webm) live in the island's Tools area via desktopCapturer.

Keys

Every action has a changeable keyboard shortcut. Ctrl+Alt+C reads the colour under the pointer and copies its hex code.

Favourite apps

Six slots, each with a global hotkey. Pick an app, set its hotkey, launch it from the Controls tab or the hotkey.
